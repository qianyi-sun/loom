# Validation artifacts

This directory contains machine-readable schemas consumed by current
repository checks. It is not a narrative documentation or release-history
area.

Native execution schemas and workload compatibility reports describe current
admission contracts. The benchmark reward contract is documented under
[`../score-alignment/`](../score-alignment/README.md).

The Slurm task-image builder conformance schemas and collection tooling have
been retired. Their source remains in Git history; see the
[retirement record](../historical/shared-cluster-retirement-2026-09.md).

Generated run reports and dated narrative summaries belong in external release
artifacts, not the repository. Older reports remain in Git history; see
[historical records](../historical/README.md).
