# Archived deployment material

These files preserve retired deployment designs, completed experiments,
superseded fleet records, and dated worker-pool evidence. They are not current
configuration or operator instructions. Use the
[current deployment architecture](../../docs/architecture/cluster-deploy.md)
and [active runbooks](../../docs/runbooks/README.md) for current behavior.

- [`dev-fleet/`](dev-fleet/) — retired development-fleet design material.
- [`envoy/spike/`](envoy/spike/) — completed Envoy bootstrap experiments.
- [`fleet-state/`](fleet-state/) — superseded fleet-state design material.
- [`worker-pools/gb10/`](worker-pools/gb10/) — dated GB10 inventory and smoke
  evidence.
- [`worker-pools/oldlab/`](worker-pools/oldlab/) — superseded Oldlab inputs,
  plans, inventory, and smoke evidence.
