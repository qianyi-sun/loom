# NOTICE

This repository ships **Loom** — an agent evaluation and training-data
generation runtime — built ground-up to replace the previous
`agentic-data-platform` content that integrated `harbor==0.9.0`.

The current architecture is documented under `docs/architecture/`
(start at `docs/architecture/overview.md`).
Pre-Loom
code, tests, docs, and configuration artifacts are preserved under
`legacy/` for historical reference; they are not wired into the build.
